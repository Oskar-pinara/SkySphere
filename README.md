SkySphere Weather Dashboard
A modern, responsive, and lightweight portable weather forecasting web application built with HTML5, CSS3, and JavaScript. Designed for users who need a fast, hassle-free, and standalone desktop experience to check real-time global weather data directly from a clean local window.

✨ Key Features:

Instant City Search: Smooth and quick searching capability for global locations with real-time weather updates.

Comprehensive Weather Metrics: Automatically extracts and displays essential atmospheric details (such as temperature, humidity, wind speed, and visibility).

Portable Desktop App: Packaged to run seamlessly as a standalone desktop window on any Windows machine using dynamic path resolution, eliminating the need for complex software installations.

Live UI Experience: Immediate rendering with a sleek design and a comfortable Dark Mode interface tailored for user convenience.

Clean Architecture: Built using lightweight web standards (index.html and configuration files) for easy sharing and maintenance.

🚀 Tech Stack:

Frontend: HTML5, CSS3, Vanilla JavaScript.

Environment: Portable Windows VBScript runner combined with Microsoft Edge's standalone --app architecture.

Deployment: Local-first, portable directory structure ready for instant sharing and distribution.
